# Introduccion a Logica difusa

Para entender la logica difusa es necesario entender la logica clasica y a partir de esta traer todas sus caracteristicas y convertirlas a este nivel.

## Logica clasica

### Conjuntos

Son agrupaciones de datos que se caracterizan por tener alguna identificacion en comun. Se nombran por las letras mayusculas y a partir de un conjunto se pueden formar otros.
```
    U = {1,2,3,4,5}
A = {1,3,4}  B = {2,4,5}
```

Existen operaciones entre conjuntos que son:

- UNIÓN
- INTERSECCIÓN
- COMPLEMENTO

Tenemos tambien la función caracteristica de un conjunto se escribe:

$$
\mu_A (u) = 1; u \in A \\
\mu_A (u) = 0; u \notin A
$$

Tambien se le conoce como *de pertenencia* o *de membresía*.
